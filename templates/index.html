Modpack import & export

Import every mod from a Modrinth modpack (.mrpack) in one go, or export everything currently installed on this server as a shareable pack.

Import a modpack

Paste a Modrinth modpack page URL or a direct .mrpack link, or upload a .mrpack file. Client-only files are skipped automatically.

Export installed mods

Builds a .mrpack from everything currently installed. Modrinth-sourced mods are re-resolved to their download links; CurseForge-only mods are listed in a text note inside the pack since they can't legally be redistributed.

Settings

CurseForge requires a personal API key. Grab one free at console.curseforge.com (Create API Key, "Core" API).

Crafty Controller API (restart hook)

Optional — lets the Installed tab trigger a server restart through Crafty right after an install or update, so the change actually takes effect. Create an API token from your Crafty user profile.

Preview mode
